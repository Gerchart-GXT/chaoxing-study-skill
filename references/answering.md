# 答题协议

适用于视频内嵌题与章节测验。核心约束：**平台只回分数，不回答案**。因此"答对"只能是推断。

## 1. 读题

优先用 DOM 文本，不要一上来就看截图：

```bash
cx.mjs watch --every 30 --checks 4     # 返回 reason=quiz 时带 quiz 文本
cx.mjs quiz                            # 章节测验全部题目与选项
```

文本不全或选项是图片时才截图，交给多模态模型看：

```bash
cx.mjs shot --path /tmp/q.png
```

## 2. 判题型

| 题型 | 依据 | 作答 |
|---|---|---|
| 内嵌题 | `reason=quiz`，只有一个弹窗 | `inline --pick <idx>`，只提交一个选项 |
| 单选 | `【Single Choice】`，`li[role=radio]` | 一个下标 |
| 多选 | `【Multiple Choice】`，`li[role=checkbox]` | 多个下标，可全选 |
| 判断 | `【True or False】` | `0` = 对/True，`1` = 错/False |

## 3. 作答

内嵌题：

```bash
cx.mjs inline --pick 0
```

章节测验（只勾选，不提交）：

```bash
cx.mjs answer --spec '{"0":[2],"1":[0,2],"2":[1]}'
cx.mjs submit
cx.mjs score
```

`--spec` 是题号到选项下标的映射，下标 0 起。`answer` 会先把选项置为指定状态再提交，因此给出完整正确答案即可，不必关心之前的勾选。

## 4. 读分与重试

```bash
cx.mjs score
```

返回 `{ total, allRight, qs:[{mark, score, mine}] }`。

| 结果 | 动作 |
|---|---|
| 满分 | 记为已确认 |
| 有错题，且可重做 | 最多重试 **2 次**：改选项 → 再提交 → 再读分 |
| 重试 2 次仍不满 | 记为**存疑**，写进笔记与最终汇报 |
| 平台不允许重做 | 直接记存疑 |

重试只对"改选可能纠正"的题有意义（多选漏选、单选看错限定词）。如果两次都指向同一处知识空缺，第三次也没用。

## 5. 存疑不阻塞

存疑是**记录问题**，不是流程错误：

- 不中断当前小节，不中断后续小节。
- 不重复无限重试。
- 只在两处呈现：该章节的 md 文档、最后的总汇报。

记录格式：

```json
{"2": {"type": "Multiple Choice", "asked": "…", "picked": ["A","B"], "score": 0,
       "note": "两次提交均判错，标准答案未公开"}}
```

## 6. 判断依据的优先级

1. 平台已判定的结果（分数、对错标记）——最高，必须服从。
2. 教材性事实（法规条文、定义、数值界值）。
3. 常识推理。

出现冲突时以平台为准，并在文档里注明"本课程按 X 判分"。例如本课程把"浓集贮存"等同于永久处置、把"一级水"归为生命科学实验用水，都与其常规含义不同。

## 7. 题型陷阱（实测）

- 判断题的限定词被替换：`可能发生` → `即将发生`、`未经授权` → `在授权情况下`。这类改动使陈述为假。
- 公式偷换：`E=mc²` 写成 `E=cm²` 即为错项。
- 多选题宁少不错：错选通常整题不得分，漏选常能拿部分分。
- 反问式单选（"下列说法中错误的是"）容易按正向理解作答，题干必须先看清。

## 8. 视觉模型什么时候必须

| 场景 | 不用视觉能否处理 |
|---|---|
| 纯文字题干 | 能 |
| 选项里有化学式/矩阵/公式图片 | 不能 |
| 题干在 canvas 里渲染 | 不能 |
| 页面结构改版、DOM 抽不到 | 只能靠截图定位 |

没有视觉能力时，遇到必须看的图，直接标存疑，不要猜。
